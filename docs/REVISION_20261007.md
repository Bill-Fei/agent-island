# 七项优化：实现与验收记录（2026-10-07）

## 实现

1. 尺寸：明确自动内容宽度与手动宽度；拖动宽度进入手动，自动 override 清除；实际尺寸展示摄像头下限的效果。空闲态不受校准影响。
2. 刷新：相同宽度、相同布局、相同应用图标/前台状态不重复发布；fresh/live/waiting/今日统计/状态签名缓存，时间边界只更新语义变化。保留 120Hz 弹簧采样，不承诺120FPS；仍是SwiftUI壳，不宣称已迁移Core Animation。
3. 状态：最近有活动与等待更新分开计数，长任务保留小态不假称执行。豆包未返回工具遵守240/1200秒边界，未知不报完成；停止跟踪不报任务中断，列表与详情统一。
4. 能力：设置与README一致说明observer-only，明确Claude Code而非普通Chat，打开应用不保证原会话定位；不启用批准回传。
5. 统计：今日活跃轮次，按本地日历00:00起、保留记录中的更新时间计数；不是API调用数。统计缓存，紧凑环形区域不抢占过多列表高度。
6. 长期运行：增量读取/后台解析、后台FIFO原子快照；每批1MiB/256行。半行不丢、超限行有诊断；失败重试最新快照不倒退游标，避免清理后复活。QA不扫描个人豆包轨迹/标题。原日志不自动删除或轮转，自动归档策略仍待产品决策。
7. 验收与发布准备：睡眠/唤醒重置交互时钟；VERSION 0.3.1、构建时间/源码指纹、Release打包、CLI和安装器随包、本地ad-hoc完整性签名、只读发布检查、清理前确认。未发布、未公证、未访问证书。首用向导/可选登录启动未实现。
