# Agent 灵动岛 · 三种核心状态

> 以下为 2026-10-08 当前运行版本的真实窗口截图。透明区域显示为白色；中态为内置尺寸预览。完整介绍见：[真实产品界面](../README.md#真实产品界面)。

这里记录三种状态之间的真实交互规则，不代表概念渲染图，也不是 NotchNook 的截图。

## 01 · 最小态

任务继续运行时，灵动岛收窄回接近物理刘海，只保留必要的 Agent 身份和动态活动提示。

![小态真实窗口截图](media/real-product-ui/01-small-state-20261008.jpg)

截图来自当时真实数据；不把待更新任务称为正在执行。

## 02 · 中态

任务开始、需要关注或结束时横向展开，短暂呈现关键状态；长任务随后回到最小态继续保留。

![中态真实界面尺寸预览](media/real-product-ui/02-middle-state-preview-20261008.jpg)

该截图由“预览中态”触发，文字“尺寸预览”不是任务事件；没有创建或修改真实任务。

## 03 · Hover 展开态

鼠标在顶部连续停留 0.2 秒后展开详情，展示最近 24 小时任务记录；移开后恢复对应状态。

![2026-10-08 当前运行版本的任务总览](media/real-product-ui/03-task-overview-20261008.jpg)

这张是当前运行版本的窗口截图；透明区域显示为白色。
