# NotchNook 录屏观察与下一轮建议

依据：用户提供的《录屏2026-10-06 11.23.04.mov》，136.4秒，60fps。
已抽看全片时间点与35—36.5秒展开/收起连续帧（20fps采样）；不是对源代码或动画参数的逆向证明。

## 录屏中确认的表现

- 顶部固定，左右及下沿从小刘海扩成黑色面板；上肩弧与下圆角随整体轮廓变化，没有另一个浮窗从上方滑入。
- 展开中先出现黑壳，内容从弱化/模糊过渡至清晰；收起时内容较早弱化，黑色轮廓继续归位。这里只能确认视觉表现，不能断言具体模糊算法或弹簧参数。
- 大态呈横向工具带，模块之间用间距和弱分隔组织，主要信息没有大量明亮卡片争抢注意力。
- 设置顶部按通用、手势、实时活动、Nook、托盘、拖放区域、许可证、关于分区。尺寸宽/高微调、内容边距、全屏策略有独立说明。
- 约72—80秒微调时，顶部出现醒目的彩色校准区域，用户能直接看到正在调整哪里；非日常显示主题。

## 建议用于我们的产品，尚未实施，待 Bill 确认

1. 动效优先：保留“始于刘海、终于刘海”，将内容清晰度与轮廓进度关联。展开略后显清晰；收起首帧就开始弱化，不等收完再改层级。继续保留200ms hover、可中途反向、减少动态效果。
2. 设置改为少量清晰分区：通用、外观与刘海、交互、Agent连接、关于。减少当前长页查找成本，不照搬无关音乐/文件托盘功能。
3. 校准增加物理边界与活动区域的短暂对照标记，分清“刘海基准”“活动翼宽”“高度微调”；日常仍纯黑，左右12pt不变。
4. 重态优先展示当前任务、真实工具步骤、待确认操作；用留白与细分隔组织，不复制横向小组件数量。

## 本轮独立实施的用户明确要求

重态轮廓内右击或Ctrl点击：设置… / 退出灵动岛。菜单打开时保持面板，取消时鼠标仍在岛内则保持展开，移出后正常收起。退出仅关闭本应用，不向Agent发送停止任务请求。

## 验收边界

本轮原生自动化仍报告Mac锁屏。右键菜单实际出现、设置路由、退出再启动，以及前轮跑马灯/呼吸观感均需解锁后核验；不能用录屏或源码验收替代。
