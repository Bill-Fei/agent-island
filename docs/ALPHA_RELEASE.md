# GitHub Alpha 发布清单

## 已纳入候选版

- 原生首用接入与验证窗口：选择 provider、展示配置路径、用户确认、备份、卸载和真实任务验证。
- observer-only 边界：不回传批准、不停止、不重试，不以模拟任务证明连接。
- 按桥接内容指纹命名，更新一个 Agent 不替换其他 Agent 仍在使用的旧桥。
- 配置读取上限、格式校验、私有权限、安装锁、冲突检测和符号链接拒绝。
- 多会话任务增加短线索与更新时间；今日统计默认收起，任务和待处理项优先。
- README、隐私说明、安全反馈入口和 GitHub 自动构建工作流。

## 仍需 Bill 最终确认

- 开源许可证：没有许可证前，GitHub 访客不能被默认授予复制、修改和再分发权限。请在公开仓库前选择 MIT、Apache-2.0 或其他明确许可；不要由工具擅自替你做法律选择。
- 发布方式：源码 Alpha，还是 Developer ID + hardened runtime + notarization 的下载包。当前只有本地 ad-hoc 完整性签名。
- 支持范围：当前候选包是 arm64；Intel、外接屏、锁屏/解锁、不同刘海尺寸和 macOS 版本仍需实机矩阵。
- 数据策略：原始事件不会自动删除；若要对外推广，应在后续版本加入可理解的保留/归档/清除入口。

## 外部 Alpha 验收

邀请 5–10 位真实多 Agent 用户，覆盖：首次安装、只接入一个 Agent、并发两个长任务、待用户确认、静默等待、完成/失败、睡眠唤醒和卸载。记录安装成功率、错误提醒率、漏提醒率、能否找到原任务、是否减少来回切换，以及 3 天后的留存使用意愿。

自动化检查通过不能替代这些真实用户证据；Hover 丝滑、物理刘海合缝和真实 provider 完成路径必须仍标记为未验证，直到获得相应证据。
