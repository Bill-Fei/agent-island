# Agent 灵动岛 Alpha 隐私说明

这是本地 macOS Alpha。默认不联网、不上传任务、不调用模型 API，也不要求 API Key。

## 会读取什么

- Codex、Claude Code、WorkBuddy：用户明确安装观察型 Hook 后，读取生命周期元数据（开始、工具阶段、等待、结束、失败等）。
- Codex / WorkBuddy：为区分最近会话，只读本地桌面显示标题；标题可能包含用户自己写入的敏感信息。
- 豆包：只读本地 Agent 模式轨迹的角色、工具类别和文件更新时间；普通聊天不可见。
- Claude Chat：辅助功能观察代码仍是实验性能力，Alpha 不保证其准确性。

不会保存提示词、聊天正文、工具输入输出、工作目录、凭据或进度百分比。事件元数据和本地标题会留在用户自己的 Mac 上，用于 24 小时显示窗口和恢复；24 小时不是自动删除期限。当前没有自动轮转或归档策略。

## 用户控制

接入和卸载均需用户确认，并先保留本地配置备份。灵动岛是 observer-only：不会在岛上批准、停止、重试或回复 Agent；需要用户决定时回原应用处理。退出 App 不会停止原应用任务，卸载接入也不会删除历史日志。

请不要把 `~/Library/Application Support/LinglongtaiHUD/`、任何 Hook 配置备份或真实标题提交到 GitHub Issue、截图或公开日志中。

## Alpha 限制

本说明描述当前实现，不构成对所有厂商版本、系统版本、屏幕布局或辅助功能状态的保证。发现隐私或安全问题，请看 [SECURITY.md](../SECURITY.md)，不要公开发布敏感样本。
