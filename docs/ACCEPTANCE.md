- 实现 Agent：修改代码、构建、运行测试、准备运行证据和复现说明。
- 验收 Agent：独立检查视觉、状态转换和边界条件，报告问题，不自行更改实现。
- 交付：先修复阻断问题，再复验。未经实际运行，不能宣称视觉或交互验收通过。
- 任何鼠标操作、App 重启、全局设置调整均与实现 Agent 协调，避免同时控制桌面。
