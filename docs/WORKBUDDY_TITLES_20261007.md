# WorkBuddy 会话标题接入（L2，2026-10-07）

## 范围

- 只补标题元数据，不修改 Hook、状态机、审批、豆包或其他会话的视觉调整。
- 数据源为本机 `~/.workbuddy/workbuddy.db` 的 `sessions` 表，只查询 `id / custom_title / title`；过滤已删除记录，优先有效手动重命名，再使用应用标题。SQL 按更新时间限定最近4096条。
- SQLite 使用只读连接与100ms忙等待，支持读取运行中数据库的WAL；不读取对话正文、工具参数、工作目录、用户ID、凭据，不复制数据库。
- 会话标识使用与WorkBuddy Hook完全相同的provider命名空间和哈希。已有通用名称的历史任务即可解析；显式指定的非通用任务名保留，未匹配不借用其他会话名称。
- 标题读取仍在utility后台每10秒执行，UI和动画帧内无数据库读取。Codex与WorkBuddy分别保留最后成功的快照，单家暂时不可用不清空另一家；成功空结果会清理该家的旧标题。
