Quiet until something needs you.

It only ever takes three shapes. No pop-ups, no stolen focus, no interruptions.

At rest

While tasks run, it stays tucked beside the notch. On the left is the agent that's working. On the right, the activity bar only means "still moving", not a progress percentage, and the number is how many tasks are running.

Alert

When a task starts, needs your confirmation, or finishes a turn, it widens for about 10 seconds to tell you which task it is and where it stands, then tucks itself away again.

Overview

Rest your pointer at the top for 0.2 seconds to see the last 24 hours: who's waiting on you, who's still running, who's done, and how many steps each turn took and whether any failed. Click "Open app" to jump to that agent; move the pointer away and it closes.

These are web recreations of the app with demo data. You'll see your own tasks.

It sees status. Never content.

Agent Island runs entirely on your Mac. It doesn't go online, doesn't upload anything, doesn't call any model API, and doesn't need an API key.

What it knows

  • Which agent is working
  • When a turn starts, waits, finishes or fails
  • The kind of step, such as reading a file or running a command
  • The task title, so you can tell tasks apart

What it never touches

  • Your prompts and chat messages
  • Tool inputs and outputs
  • Accounts, credentials and API keys
  • The contents of your files

Before connecting each agent, it tells you which config file it's going to change. It only writes after you confirm, keeps a backup of the original, and you can disconnect at any time.

By default it only observes and never decides for you. The one exception is Claude Code: you can turn on one-time approval. Each request then grows out of the notch as a card showing what will run and how long is left; Allow lets through that one request, and risky ones such as deletes or pushes need a 0.6-second press and hold. Confirmations for every other agent stay in that agent's own app.

Agents you can connect today

The Alpha starts with these. Each status is stated plainly, not oversold.

  • Codex Connects through lifecycle hooks Tested on real hardware
  • Claude Code Connects through lifecycle hooks, with optional one-time approval Tested on real hardware
  • Work Buddy Connects through lifecycle hooks Tested on real hardware
  • Doubao Reads only local Agent-mode records; regular chats stay invisible Read-only
  • Claude desktop app Needs Accessibility permission; not covered by the Alpha yet Experimental

Icons in the app come from the agents installed on your Mac; any you don't have show a generic placeholder.

Download the Alpha Mirror in China

The installer is being prepared. Once it's published, you can download it here.

  1. Drag it into ApplicationsOpen the downloaded .dmg and drag Agent Island into your Applications folder.
  2. Open it the first timeIf macOS says it can't be opened, go to System Settings › Privacy & Security and click "Open Anyway".
  3. Connect your agentsClick the island icon in the menu bar, choose "Connect & Verify…", and tick only the agents you use.
  4. Run one taskStart a real task in the agent's own app, then come back and check that the island lights up.

Why step two: the Alpha isn't notarized by Apple yet, so macOS asks once on first launch. Prefer to build it yourself? View the source on GitHub.

This site counts visits, main button clicks, installer download requests and country/region totals, kept for 90 days. It uses no cookies, stores no raw IP addresses, and collects nothing from the app's tasks or conversations. A download request doesn't mean a finished download, and the Agent Island app itself never goes online. Nothing is recorded when your browser has Do Not Track or Global Privacy Control turned on.
