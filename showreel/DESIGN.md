# Quiet Power · Agent 灵动岛

## Style Prompt
发布会级的精密动态设计：曜石黑、瓷白、产品原有的薄荷信号色；金属轮廓与局部柔光，巨幅排版、克制留白。先把无形的 Agent 活动变成可感知的信号，再展示 macOS 顶部的轻量状态层。每一段技法都服务于产品语义，不将技术演示误写成产品功能。

## Colors
- #090c0e — 曜石底色
- #f7f7f4 — 瓷白主体
- #79f2b5 — 活动信号 / 主强调色，来自产品 BrandMark
- #84dbf3 — 第二信号，来自产品 BrandMark，低比例
- #7f9292 — 辅助注释

## Typography
系统 Helvetica Neue / PingFang SC：大字 500–700，说明 300–400。
系统 Menlo：工程标记、节奏编号。无字体下载、无远程媒体。V2 按 Bill 最新要求使用本机应用原始图标与项目存档的真实 UI 截图。

## Motion
120 BPM / 四拍一段 / 2 秒一个主题。26 秒以前 13 段；26–30 秒品牌收尾。
变形有物理重量、曲线有明确目的；低干扰活动信号与高能量转场对比。
每段采用不同转场，所有切点落在 0.5 秒节拍栅格；转场从切点开始。
25.5–26 秒完全静音一拍，26 秒原创重击进入品牌。开场小球最后落为名称句点。

## What NOT to Do
- 不仿制厂商 Logo；只读取已安装应用图标。不读取运行时任务数据；存档截图的会话标题、URL、标识脱敏。
- 不承诺跨端执行、手机系统能力、全 Agent 审批或推测进度。
- 不用廉价满屏渐变、不做持续闪烁与赛博噪声。故障段仅为一次受控技法。
- 不把概念图当成实机截图；真实界面注明存档时间，游标与点击圈属于操作示意，不是假称实机录屏。
- 不下载图片、视频、音频、字体或 CDN；本地真实产品素材为本轮明确授权的例外。

## Story / 技法 / 转场
| 时间 | 技法 | 产品语义 / 场景 | 从此段进入下一段 |
|---|---|---|---|
| 00–02 | 弹跳小球 / 挤压拉伸 | 一个轻量信号，工作被看见 | 圆形虹膜 |
| 02–04 | 逐字动态排版 | Agent 在工作，你继续专注 | 字幕横向推移 |
| 04–06 | 形状变形 | 最小态 / 事件态 / 悬停详情 | 轮廓挤压 |
| 06–08 | 缓动曲线 + 真实设置页 | 出现方式、悬停详情的用户控制 | 斜向切片 |
| 08–10 | 9000 粒子拼字 | 多 Agent，同一个入口 | 深度推进 |
| 10–12 | 纯代码 3D 点云 | 状态有迹，不推测进度 | 景深交叠 |
| 12–14 | 银白液态元球 | 聚合而非堆叠，取消绿色团块与岛拼贴 | 液态圆片揭示 |
| 14–16 | 瑞士网格波 | 写代码 / 查资料 / 整理工作，多任务一眼掌握 | 网格阶梯快门 |
| 16–18 | 克制故障 + 真实操控页 | 小态/中态预览按钮、恢复自动尺寸 | 横向条带位移 |
| 18–20 | 景深缩放 + 完整真实详情 | 悬停 0.2 秒，不裁切 UI 内部布局 | 刘海形镜头开合 |
| 20–22 | 等距城市 + 真实 Agent 页 | 接入状态一眼可知 | 等距对角滑移 |
| 22–24 | 单线谐波 + 真实任务详情 | 查看已返回步骤 / 打开应用按钮 | 线性扫描揭示 |
| 24–26 | 加速快切回顾 | 看见 / 专注 / 掌控 | 静默与球体落点匹配 |
| 26–30 | Logo 收尾 | Agent 灵动岛 · 你的 Agent 管家 | 稳定落版 |
